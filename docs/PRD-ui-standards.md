# PRD：前端 UI 規範統一（ui-standards）

> 版本：1.1.0 ｜ 狀態：完成 ｜ 最後更新：2026-11-12

## 目標

目前各畫面的按鈕、表格、分頁、表單是逐一手寫的 Tailwind class，尺寸與顏色不一致，也有明顯的版面問題：生命徵象面板被拉高時分頁列停在中間、下方留白；Tailwind v4 預設框線顏色是文字色，表格分隔線變成黑線；主要按鈕的藍色對比不足。本功能訂出一套全站共用的 UI 規範，並把所有畫面改成符合規範。

## 決策

| 項目 | 決定 | 理由 |
|------|------|------|
| 實作方式 | 在 `src/assets/main.css` 以 `@layer components` 定義少量共用 class（按鈕、表單、卡片、表格、提示），畫面只用這些 class 加版面用 utility | 不新增套件；同一種元件只有一個定義，改一處全站一致 |
| 參考標準 | WCAG 2.2 AA（對比、焦點、鍵盤）；常見設計系統（Ant Design、Material、Carbon）的表格、分頁、表單、對話框慣例 | 業界通用、面試時說得出依據 |
| 新元件 | `PageHeader`（頁面標題、說明、主要操作） | 每頁一個 h1，主要操作位置固定 |
| 範圍 | 只改畫面與樣式，不改 API、store 邏輯與文案意思 | 降低風險 |

## 規範

**版面**
- 內容最大寬度 1280px（`max-w-7xl`）置中，左右留白 16px（手機）／24px（`sm` 以上）。
- 頁首：系統名稱、導覽、使用者與登出；目前頁面以底線標示並設 `aria-current="page"`。窄螢幕導覽可水平捲動。
- 每頁一個 `h1`（`PageHeader`），主要操作（新增）放在標題列；病人詳細頁加導覽路徑（病人 / 姓名）。
- 換頁面時捲到頁首；瀏覽器上一頁／下一頁回到原本的捲動位置。

**卡片**
- 結構：標題列（`card-header`）／工具列（`toolbar`，篩選條件）／內容／頁尾（`card-footer`）。
- 分頁列一律放在卡片頁尾，卡片被拉高時頁尾仍貼齊卡片底部（`flex-col` + `mt-auto`）。

**按鈕**
- 高度：一般 36px、小 32px；字級 14px；圓角 6px。
- 層級：主要（實心 `sky-700`，白字對比 5.9:1）、次要（白底灰框）、危險（實心 `rose-600`，只用於確認對話框的確定）、危險外框（停用等）。
- 一個區塊只有一個主要按鈕。
- 表格列內操作用文字按鈕（編輯、查看、刪除、停用），危險操作用紅字。
- 對話框與表單的按鈕靠右，取消在左、主要按鈕在右。
- 所有可互動元素有清楚的 `:focus-visible` 外框；停用狀態降低透明度且游標為 not-allowed（`disabled` 與 `aria-disabled` 都適用）。
- 對話框關閉後焦點回到開啟它的按鈕；按鈕已不存在時移到 `<main>`。列上的操作按鈕在處理中用 `aria-disabled`，不用 `disabled`（`disabled` 會讓按鈕失去焦點）。按鈕操作後會消失時（例如報到），焦點移到同一列的其他控制項。

**表單**
- 標籤在欄位上方（14px、中等字重）；必填加紅色「*」並附螢幕閱讀器可讀的「必填」。
- 欄位高度 36px、灰框、圓角 6px；數值範圍與單位放在標籤或說明文字，不用 placeholder 取代標籤。
- 錯誤訊息以 `role="alert"` 提示框顯示在按鈕上方。

**表格**
- 表頭淺灰底、12px 粗體；列分隔線淺灰；滑過整列變色。
- 數值欄靠右並使用等寬數字（`tabular-nums`）；單位寫在表頭。
- 最後一欄「操作」靠右。
- 窄螢幕不換行，外層水平捲動。「操作」欄固定在右側（sticky），捲動時仍看得到。

**分頁**
- 左側「共 N 筆，第 a–b 筆」；右側上一頁、頁碼（前後省略號）、下一頁、每頁筆數。
- 沒有資料時不顯示；只有一頁時不顯示頁碼。

**狀態**
- 載入中、空資料（標題＋說明＋下一步按鈕）、錯誤（紅色提示框＋重試）三種狀態樣式全站一致。
- 狀態徽章為圓角膠囊、淺底深字，一定有文字。

## 開發紀錄

完成日期：2026-11-11。

**實際做法**
- `src/assets/main.css`：`@layer base` 把預設框線改成 `slate-200`、統一 `:focus-visible` 外框；`@layer components` 定義 `btn` 系列、`form-label` / `form-control` / `form-hint`、`card` 系列、`toolbar`、`data-table`（含 `num`、`unit`、`col-actions`）、`alert-error` / `alert-info`、`empty-state`、`badge`。
- 新增 `PageHeader`（標題、說明、導覽路徑、主要操作）。所有頁面改用 `PageHeader` 加卡片結構。
- 頁首改為白底、內容置中 1280px，導覽以底線標示目前頁面，並加上「跳到主要內容」。
- `PaginationBar` 由父元件以 `class="card-footer mt-auto"` 放在卡片頁尾；卡片為 `flex-col`，被拉高時分頁列貼齊底部（AC-01）。
- 表格列內操作改成文字按鈕；生命徵象等窄表格的「操作」欄固定在右側（`sticky`），水平捲動時仍看得到。
- 生命徵象表頭加單位（mmHg、次/分、mg/dL、kg），數值欄靠右、等寬數字。
- 量測表單改成欄位定義陣列產生，標籤與輸入框以 `id` 關聯，範圍放在說明文字。
- 表單、對話框的按鈕統一靠右（取消、主要按鈕）。對話框加右上角關閉按鈕。
- 錯誤提示的 toast 改用錯誤圖示（`showToast(text, 'error')`），不再和成功提示長得一樣。
- 換頁面時捲到頁首，上一頁／下一頁時回到原本的位置（router `scrollBehavior`）。

**與 PRD 的差異**
- 窄表格「操作」欄固定在右側、router 捲動行為是驗證時發現的問題，已補進規範本文。

**驗證方式**
- `npm run build` 無錯誤；瀏覽器 console 沒有錯誤。
- 門診作業：選取病人後生命徵象面板與清單等高，分頁列在面板底部；選取列有左側色條；病人姓名是按鈕，可以用鍵盤操作。
- 病人清單、病人詳細頁（表單、量測表單）、醫師（新增對話框）、科別：用畫面檢查樣式。
- 400px：以 iframe 載入五個頁面，`scrollWidth` 都不超過 400；病人詳細頁與生命徵象表格目視正常。

**第二輪驗收（2026-11-12）**
- AC-01：門診作業選取病人後兩張卡片都是 742px 高，分頁列與面板底部相差 1px（框線）。
- AC-02：表格分隔線為 `slate-100`，沒有深色框線。
- AC-03：五個頁面都有 `h1`。
- AC-04：日期、下拉、查詢按鈕高度都是 36px；主要按鈕與文字按鈕對比 5.86:1，說明文字 4.76:1。
- AC-05：用 Tab 鍵移動，焦點外框為 `sky-500` 實線並帶 `:focus-visible`。發現對話框關閉後、報到後焦點會遺失，已修正並補進規範本文（焦點規則、`aria-disabled`）。
- AC-06：號碼、血壓、心跳、血糖、體重靠右，表頭有單位。
- AC-07：以 400px iframe 載入門診作業、病人、病人詳細、醫師、科別，頁面都沒有水平捲動，寬表格在卡片內捲動。
